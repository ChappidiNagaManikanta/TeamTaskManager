# Railway Deployment Steps

This guide explains how to deploy the Team Task Manager to Railway (railway.app).

## 1. Prepare GitHub Repository
Push the `TeamTaskManager` folder to a single GitHub repository.

## 2. Deploy MySQL Database
1. Go to Railway Dashboard and click `New Project`.
2. Select `Provision PostgreSQL` or `Provision MySQL` (Select MySQL).
3. Wait for the database to provision. Go to the Variables tab of the database to find your `MYSQL_URL`, `MYSQL_USER`, `MYSQL_PASSWORD`, etc.

## 3. Deploy Spring Boot Backend
1. In the same Railway project, click `New` -> `GitHub Repo`.
2. Select your repository.
3. Railway needs to know to build the `backend` folder. Set the **Root Directory** setting to `/backend` under Settings.
4. Add the following Environment Variables in the Backend service Variables tab:
   - `SPRING_DATASOURCE_URL`: jdbc:mysql://${MYSQLHOST}:${MYSQLPORT}/${MYSQLDATABASE}
   - `SPRING_DATASOURCE_USERNAME`: ${MYSQLUSER}
   - `SPRING_DATASOURCE_PASSWORD`: ${MYSQLPASSWORD}
   - `PORT`: 8080 (Railway will use this to bind the port)

## 4. Deploy React Frontend
1. In the same Railway project, click `New` -> `GitHub Repo` and select the repo again.
2. Set the **Root Directory** setting to `/frontend` under Settings.
3. Railway will detect Vite and build it automatically.
4. Go to Settings -> Environment Variables and add:
   - `VITE_API_URL`: The public URL generated by Railway for your backend service (e.g., `https://your-backend-url.up.railway.app/api`).
   *(Note: You will need to update `axios.js` in the frontend to use this variable instead of localhost)*
5. Go to Networking and click `Generate Domain` to get a public URL for your frontend.
